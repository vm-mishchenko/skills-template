# Example template

Supporting material that skills and commands link to: templates, checklists, style guides, domain
notes. Nothing here loads automatically. Keep it here when more than one skill or command needs it,
otherwise inside the skill's own `references/`.

Delete this file and add your own.

## Template: change proposal

- Goal: one sentence
- Current state: what exists today
- Proposed change: what should be different, not how to build it
- Out of scope: adjacent work not included
- Open questions: items to resolve before implementation
